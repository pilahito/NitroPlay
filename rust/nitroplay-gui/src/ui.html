Consola

Para vincular tu PS4/PS5
  1. En la PS5: Ajustes → Sistema → Remote Play → Vincular dispositivo. Anota el PIN de 8 dígitos (caduca en minutos).
  2. Ten a mano tu Account-ID (pestaña Cuenta PSN).
  3. El registro y la transmisión los hace el cliente NitroPlay de transmisión (Android/escritorio), no esta ventana.

HDR y alta calidad

Cómo activarlo en el cliente de transmisión
  • Configuración → Vídeo: selecciona Vulkan.
  • Transmisión → PS5: selecciona H265 HDR (conexión local y, si hace falta, Internet).
  • Nitidez ajustable en Configuración → Vídeo: Apagado, Baja, Media o Alta.
  • Para ver HDR real, el monitor, Windows, el controlador y la salida de vídeo deben admitirlo.

Esta ventana no transmite vídeo: estos ajustes se aplican en el cliente de transmisión.
